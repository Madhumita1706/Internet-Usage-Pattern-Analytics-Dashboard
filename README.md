# Internet Usage Pattern Analytics Dashboard

## Overview
This project presents an interactive data analytics dashboard developed to
examine internet usage patterns among a sample population of 2,800 users
over the period January–December 2024. The dashboard was designed as part
of a data analytics assignment, applying principles of exploratory data
analysis (EDA) and data visualization to derive insights into user behavior
across demographic and technological segments.

## Objective
The primary objective of this study is to analyze how internet usage
patterns — specifically screen time, social media usage, work/study
activity, and entertainment consumption — vary across age groups, internet
connection types (WiFi vs. Mobile Data), and primary devices (Mobile,
Tablet, Laptop).

## Methodology
The dashboard implements client-side filtering and aggregation logic to
compute descriptive statistics (means, counts, percentage compositions)
from the underlying dataset in real time, in response to user-selected
filter criteria (date range, age group, internet type, device type).

## Key Visualizations
1. **Combo Chart** — Average screen time and user count distribution by age group
2. **Radar Chart** — Comparative usage profile (Social Media, Work/Study, Entertainment) across internet connection types
3. **Scatter Plot** — Relationship between age and total screen time, segmented by device
4. **Stacked Bar Chart** — Compositional breakdown of usage categories by age group
5. **100% Stacked Horizontal Bar** — Relative device usage share within each age group
6. **Trend Line Chart** — Temporal trend of average screen time (daily/monthly granularity)

## Tools and Technologies
- HTML5, CSS3
- JavaScript (ES6)
- Chart.js library for data visualization

## How to Run
Clone or download the repository and open `index.html` in any modern web
browser. No installation, server, or external dependencies are required,
as the dataset and rendering logic are fully self-contained.
